# Fullstack learning tracker

This repository holds one [fullstack roadmap](ROADMAP.md), my [study notes](NOTES.md), and a [weekday study log](STUDY_LOG.md).

I work through one small subtopic on weekdays. After studying, I write a short cheatsheet, describe a 15–20 minute practical task, and record how the topic felt. I commit the note before moving to the next subtopic.

The roadmap combines the supplied curriculum with [roadmap.sh Backend](https://roadmap.sh/backend), [API Design](https://roadmap.sh/api-design?fl=1), and [Fullstack Transition for Frontend Developers](https://roadmap.sh/ai/roadmap/fullstack-transition-for-frontend-developers-eqv75). The JSX curriculum is archived in [sources](sources/fullstack-curriculum-tracker.jsx) for reference; `ROADMAP.md` is the only active roadmap.

## Daily routine

1. Open [ROADMAP.md](ROADMAP.md) and find the current subtopic ID.
2. Pick one relevant link and study it. Do a small practical task.
3. Add your own entry to [NOTES.md](NOTES.md) using its template.
4. Commit the notes and check off the subtopic. Record a skipped day in [STUDY_LOG.md](STUDY_LOG.md).

An assistant can suggest resources, explain ideas in simple words, and give hints. I write and solve the practice work myself.
